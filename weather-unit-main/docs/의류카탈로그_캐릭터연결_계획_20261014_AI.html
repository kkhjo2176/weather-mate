옷 추천 결과를 캐릭터에 연결하는 계획

2026-10-14 · 남은 기간 3~4일 · 근거 = clothing-catalog.json(170개) 분석 + 백엔드가 보낸 API 결과 예시

결론. 옷 170개마다 캐릭터를 그리는 건 불가능합니다. 대신 캐릭터는 대표 착장 8~11벌만 미리 만들고, 정확한 옷은 아이콘과 이름으로 보여 주는 방식이면 3~4일 안에 됩니다.

날씨 계산은 우리가 안 해도 됩니다. 백엔드 API가 이미 날씨(기온·하늘·강수·습도)를 보고 옷 조합을 골라서 보내 줍니다. 우리는 그 결과를 받아서 그림만 골라 붙이면 됩니다.

1. 지금 데이터가 어떻게 흘러오나

① 백엔드날씨 계산기온·하늘 상태·강수량·습도
② 백엔드카탈로그에서 옷 고름상의·하의·아우터·신발 등 칸마다 C019 같은 번호 1개
③ API 결과outfits JSON예: 후드티 C019 + 조거 C045 + 블루종 C058 + 운동화 C138
④ 우리 몫번호 → 그림미리 만든 캐릭터 1장 + 옷 아이콘 4~5개를 골라 화면에 붙임

그래서 "오늘 25도에 불쾌지수 낮은 가을"을 우리가 판단할 필요가 없습니다. 백엔드가 그 날씨에 맞는 옷 번호를 주면, 그 번호에 맞는 그림을 꺼내 쓰기만 합니다.

2. 왜 170개를 다 그릴 수 없나

방식만들어야 할 그림판정이유
옷 조합마다 캐릭터 1장약 50만 장
상의 45 × 하의 41 × (아우터 45+없음) × 신발 6, 여성용만, 기온 조건 무시한 계산		불가능API가 칸마다 따로 고르기 때문에 조합 수가 폭발합니다.
옷 1개마다 투명 레이어를 겹쳐 입히기 (옷 갈아입히기 인형)옷 레이어 약 150장 + 몸 1장위험모든 옷이 같은 자세·같은 위치에 딱 맞아야 합니다. AI 그림은 매번 위치가 조금씩 달라서 3~4일 안에 맞추기 어렵습니다.
대표 캐릭터 + 옷 아이콘 (추천)캐릭터 8벌(있음) + 빈칸 3벌 + 아이콘 약 30개가능캐릭터는 "어떤 느낌의 옷차림인지"를 보여 주고, 실제로 추천된 옷은 아이콘과 이름으로 정확히 보여 줍니다.

3. 170개를 아이콘 약 30개로 줄이는 법

카탈로그를 보면 이름만 다르고 쓰임이 같은 옷이 많습니다. 여성용(남성 전용 6개 제외)·집옷 제외 150개는 기온 범위와 방수·방풍 점수가 완전히 같은 34묶음으로 나뉩니다. 이걸 눈으로 구별되는 모양 기준으로 다시 묶으면 아이콘 약 30개면 됩니다.

아이콘 밑에는 API가 준 실제 이름(예: "블루종")을 그대로 씁니다. 그래서 아이콘이 묶음이어도 사용자에게는 정확한 옷 이름이 보입니다. 170개 번호 전부가 어느 아이콘인지 적은 표(item_icon_map.json)를 프로그램으로 만들어 빠지는 번호가 없게 합니다.

4. 캐릭터는 어떻게 고르나 (아우터 × 하의 모양)

API 결과에서 아우터 종류와 하의 모양 두 가지만 보고 미리 만든 캐릭터 중 하나를 꺼냅니다. 계절 이름이 아니라 옷 모양으로 고르기 때문에 "25도 가을"이든 "25도 봄"이든 같은 옷이면 같은 캐릭터가 나옵니다.
