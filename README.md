# weather-life

기상 예측 및 생활 정보 팀 프로젝트입니다.

- `weather-life/`: Java / Spring 백엔드
- `ai-service/`: Pangu 예측 및 FastAPI 서비스

## 팀원 컴퓨터에서 Pangu CPU와 API 실행

[설치부터 실제 예측 및 API 실행까지의 안내](ai-service/README.md)를 순서대로 따라 하세요.
코랩과 DB 없이 Windows 컴퓨터에서 실행합니다. 모델과 기상자료는 각 컴퓨터에서 다운로드합니다.
CPU 예측은 메모리 제한 실행기를 사용하며, 예측이 성공해야 실제 결과를 조회할 수 있습니다.
