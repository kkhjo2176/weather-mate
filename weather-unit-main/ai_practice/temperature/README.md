# ASOS 기온 예측 연습
1. Google Colab에서 **파일 → 노트북 업로드**로 `기온예측_연습_ASOS_codex.ipynb`를 엽니다.
2. 위에서부터 실행하고 업로드 창에 `data/ASOS_서울108_2020-2025_병합.csv` **한 개**를 넣습니다(또는 원본 CSV 6개).
3. 병합본과 원본을 함께 올리지 마세요. 날짜 중복 오류가 납니다.
4. 기본 대상은 기온이며 시험 연도는 마지막 연도(현재 자료 2025년)입니다.
5. 습도 연습은 노트북의 `TARGET` 한 줄을 바꾼 뒤 처음부터 다시 실행합니다.
