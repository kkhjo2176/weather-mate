# weather-life

기상 예측 및 생활 정보 팀 프로젝트입니다.

- `weather-life/`: Java / Spring 백엔드
- `ai-service/`: Pangu GPU 예측 자동 갱신 및 FastAPI

## 컴퓨터를 켠 뒤 API와 자동 예측 시작하기

[초보자용 실행 안내](ai-service/README.md)에 최초 설치와 매일 실행할 명령어 두 개를 정리했습니다.

API 서버와 자동 갱신 프로그램을 각각 실행해 두면, 사용할 수 있는 새 기준일의 ECMWF 자료를 확인하고 GPU 예측 결과를 자동으로 반영합니다. 기본 확인 간격은 10분입니다.

오늘·내일·모레 오전 9시를 같은 초기자료로 예측하는 조건을 유지하므로, 기준일마다 통상 하루 한 번 갱신합니다. ECMWF가 공개하는 모든 6시간 주기를 사용하는 방식은 아닙니다.

코랩과 DB는 필요하지 않습니다. 컴퓨터가 꺼져 있거나 절전 상태면 서비스가 작동하지 않습니다.
