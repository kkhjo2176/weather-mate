## 확인한 내용

- 첨부 목록과 36세트/56의류/19소품의 key와 표시 이름이 정확히 일치합니다.
- 성별 3종 × 기온 6종 × 강수 2종 × 풍속 2종 = 72가지 요청에서 세부 옷이 선택 세트의 허용 항목에만 속하는지 확인했습니다.
- 원피스와 상하의 조합이 섞이지 않고, 슬롯 중복·성별 불일치·등록되지 않은 이미지 세트가 없는지 확인했습니다.
- 쌀쌀한 여름/더운 가을에서 날씨가 달력 계절보다 우선합니다.
- 일상/출근/운동/HOME 필드가 세트 선택 및 기온 보정을 제한하지 않습니다.
- 온화한 날의 빈 소품 배열, 우산/접이식 우산 구분, 장화, 알려진 미세먼지, 추위/더위/강풍 소품을 확인했습니다.
- 눈에는 접지력 있는 방수 방한화, 추위에는 내의를 추가합니다.
- 일교차 때문에 그림에 없는 겉옷을 입히지 않고 소품으로 챙기도록 안내합니다.
- 기본 1세트, 명시한 count의 대안 세트, 동일 seed 재현, 잘못된 입력 400, 없는 성별/선호 세트 422를 확인했습니다.
- DB 예보 API의 gender/날짜/강수확률 전달과 기존 날씨 API 응답을 확인했습니다.
- PCP의 숫자·범위·이상·미만·강수없음 처리와 누락값의 null 유지를 확인했습니다.
- 기존 불쾌지수/수집/보관기간 관련 테스트도 통과했습니다.

## 검증 범위의 한계

- 실제 캐릭터·아이콘 파일과 프론트 JavaScript는 제공되지 않았습니다. 경로 및 데이터 연결을 검증했으며 화면 표시·동영상 재생을 직접 확인하지는 않았습니다.
- 일반 코트/패딩/바람막이에 방수 성능을 부여하지 않습니다. 추운 비·눈에 필요한 보호는 추천 안내와 실제 의류 성능을 함께 확인해야 합니다.
- 가중치와 권장 기온은 프로젝트의 경험 규칙입니다. 실제 착용 평가 또는 학습 모델 검증 결과가 아닙니다.
